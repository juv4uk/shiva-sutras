# Kṣetra: Śiva-sūtras

Цей розділ фіксує суворі епістемічні шари (Kṣetra) нашого об'єкта дослідження. Шари не повинні змішуватися:

1. **CANON**: 14 сутр, порядок звуків (sequence), it-маркери (markers).
2. **PĀṆINIAN FORMAL USE**: Конструкція pratyāhāra, вирішення неоднозначностей входжень, застосування в Aṣṭādhyāyī.
3. **TRADITIONAL INTERPRETATION**: Традиційні коментарі.
4. **MODERN SCHOLARSHIP**: Академічна лінгвістика/фонетика.
5. **OUR HYPOTHESES**: Гіпотези.
6. **ENGINEERING**: Інженерні проєкції (напр. машинне кодування).

У цій директорії `canon` ми будемо збирати джерелознавчі дані щодо походження самих 14 сутр.
