# Historical Archive

Ця директорія містить файли, скрипти та проміжні результати, які були важливими для розвитку проєкту на різних етапах, але наразі не використовуються в активному пайплайні. Вони збережені тут заради цілісності журналу дослідження та історії еволюції методів.

## Статуси файлів

Щоб не створювати шуму для поточних досліджень, файлам тут присвоєно один із наступних статусів (вказаних у коментарях або логах):

- **`SUPERSEDED`**: Замінено новішою, ефективнішою або правильнішою версією (наприклад, `candidate_annotation_v2.py` замінено на `v5_1`).
- **`FALSIFIED`**: Містить гіпотезу або підхід, що був перевірений і спростований під час дослідження.
- **`HISTORICAL`**: Тимчасовий скрипт для разової міграції даних, парсингу або аналізу, який виконав свою роль і більше не потрібен (наприклад, `upgrade_schema.py`).
- **`SYNTHETIC-ONLY`**: Інструмент або дані, що використовувалися для моделювання ситуації (симуляції експертизи чи джерела), які не претендують на історичну правдивість.

Усі файли в цій директорії можна вважати `Read-Only` архівом.
