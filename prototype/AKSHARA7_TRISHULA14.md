# Дві власні версії коду Śiva-sūtra

Це два незалежні експерименти поверх канонічного порядку сутр. Вони не змінюють `ksetra/` і не претендують на історичний або апаратний результат.

## akṣara7

Формат клітини: `family[2] + payload[5]`.

- `00xxxxx` — один із 42 звуків;
- `01xxxxx` — службова клітина маркера сутри;
- `10xxxxx` — зарезервовані оператори;
- `11xxxxx` — заборонена область.

Код звуку не залежить від IAST/SLP1-виводу. `bits()` показує рівно 7 біт, а `check()` не ремонтує неправильні клітини.

## triśūla14

Формат клітини: `kind[3] + index[5] + variant[3] + voice[1] + aspiration[1] + length[1]`.

Це не просто номер звуку: декодер бачить тип (голосний, зімкнений, сонорний, сибілянт, гортанний), локальний індекс і маленькі ознаки. Усі 42 канонічні комбінації мають різні 14-бітні коди; валідна форма поля, яка не призначена канонічному звуку, відхиляється.

## Запуск

```bash
cd prototype
python3 -m unittest -v test_akshara7_trishula14.py
```

Обидві версії мають однакову демонстраційну операцію `pratyahara("a", "ṇ")`, але реалізують її незалежно.
