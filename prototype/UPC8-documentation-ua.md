# UPC-8: Універсальний Фонемний Код (8 біт)

Документація прототипу. Версія: v0.2 (frozen architecture).

---

## Архітектура

```
КАНОН (Шіва-сутри, незмінний)
  └→ Санскрит (академічна інтерпретація)
       └→ Мовні розширення (Українська, Англійська, ...)
            └→ UPC-8 (8-бітне кодування)
                 └→ FPGA (апаратна реалізація)
```

Шіва-сутри — **незмінний канонічний шар**. 14 с̄утр, 43 позиції, 42 унікальних звуки (звук h зустрічається в с̄утрі 5 та с̄утрі 14, але має один код 0x09). Усі інші шари посилаються на канон, але не змінюють його.

## Розподіл кодового простору

| Діапазон | Шар | Кодів | Опис |
|---|---|---|---|
| 0x00–0x29 | Канон (Шіва-сутри) | 42 | Звуки в послідовності канону, незмінні |
| 0x2A–0x30 | Санскрит розширений | 7 | Довгі голосні, анусвāра, вісарга |
| 0x31–0x4F | Українська (нові) | 31 | near-equivalent + new-extension |
| 0x50–0x7F | Англійська (reserved) | 0 | Майбутнє |
| 0x80–0xFF | Reserved | 0 | Майбутні мови |

**Призначено: 80 кодів (31.2%). Зарезервовано: 176 кодів (68.8%).**

Українська також використовує 13 канонічних кодів (спільні звуки: /i/, /u/, /k/, /p/, /b/ тощо) — вони не займають нових кодів.

## Шіва-сутри (канон)

14 с̄утр, кожна — впорядкований список звуків, що завершується маркером (it/anubandha). Маркер виключається з пратьāхāри-множини.

| № | Звуки (SLP1) | Маркер | Звуки (IAST) |
|---|---|---|---|
| 1 | a i u | R (Ṇ) | a i u |
| 2 | f x | k (K) | ṛ ḷ |
| 3 | e o | N (Ṅ) | e o |
| 4 | E O | c (C) | ai au |
| 5 | h y v r | w (Ṭ) | h y v r |
| 6 | l | R (Ṇ) | l |
| 7 | Y m N R n | m (M) | ñ m ṅ ṇ n |
| 8 | J B | Y (Ñ) | jh bh |
| 9 | G Q D | z (Ṣ) | gh ḍh dh |
| 10 | j b g q d | S (Ś) | j b g ḍ d |
| 11 | K P C W T c w t | v (V) | kh ph ch ṭh th c ṭ t |
| 12 | k p | y (Y) | k p |
| 13 | S z s | r (R) | ś ṣ s |
| 14 | h | l (L) | h |

Примітки:
- Звук **h** зустрічається двічі: с̄утра 5 (позиція 1) та с̄утра 14 (позиція 1). Обидві позиції мають код 0x09. Позиція в с̄утрі 14 записана як `alias_sutras: [14]`.
- Маркер **Ṇ** (R) використовується в с̄утрах 1, 6 та 13. Пратьāхāра визначає, яке входження мається на увазі, скануючи зліва направо від початкового звуку.

## Пратьāхāра (природні класи)

Пратьāхāра — механізм Паніні для позначення класів звуків. Реалізує правила 1.1.62–1.1.64:

- **Перший символ** = ādi (початковий звук, входить до множини)
- **Останній символ** = it (маркер, виключається з множини)
- **Діапазон** = усі звуки від початкового до кінця с̄утри маркера, мінус сам маркер
- **Скан маркера** = зліва направо від с̄утри початкового звуку

| Пратьāхāра | Значення | Кількість | Звуки |
|---|---|---|---|
| `ac` | усі голосні | 9 | a i u ṛ ḷ e o ai au |
| `hal` | усі приголосні | 32 | h y v r ñ m ṅ ṇ n jh bh gh ḍh dh j b g ḍ d kh ph ch ṭh th c ṭ t k p ś ṣ s |
| `ik` | вузькі голосні | 4 | i u ṛ ḷ |
| `Sar` | шиплячі | 3 | ś ṣ s |
| `yaR` | напівголосні | 4 | y v r l |

Приклад: `ac` = звук a (с̄утра 1) → маркер Ṅ (с̄утра 4) = a, i, u, ṛ, ḷ, e, o, ai, au (9 голосних). Маркер Ṅ(c) виключається.

## Нерозв'язані IPA значення

Деякі фонеми мають IPA значення, що є спірним або контекстно-залежним. Вони позначені `ipa: "unresolved"` зі списком кандидатів — без примусового вибору одного значення.

| Код | Фонема | Кандидати IPA |
|---|---|---|
| 0x2A | a: (довга a) | A:, a:, @ |
| 0x2F | ~ (анусвāра) | m~, N, n, m |
| 0x30 | H (вісарга) | h, x, c< |
| 0x31 | и | I, e, M |
| 0x33 | а | a, A |
| 0x34 | о | O, o |
| 0x3E | г | G\, x, 7 |
| 0x40 | в | v, w, B\ |

## Використання

```python
from upc8 import UPC8

u = UPC8()

# Кодування санскриту (SLP1 або IAST)
code = u.encode_sanskrit('a')        # → 0x00
code = u.encode_sanskrit('ā')        # → 0x2A (довга голосна)

# Кодування української
code = u.encode_ukrainian('і')      # → 0x01 (спільний канонічний код)
code = u.encode_ukrainian('ш')      # → 0x3B (новий код)

# Кодування слів
u.encode_sanskrit_word('karma')     # → b'\x25\x00\x0c\x0f\x00'
u.encode_ukrainian_word('джаз')     # → b'\x38\x33\x3a'

# Декодування
info = u.decode(0x00)                # → {code: 0, layer: 'canonical', slp1: 'a', sutra: 1, ...}

# Пратьāхāра (розширення природних класів)
u.pratyahara('ac')                  # → [0x00, 0x01, ...] — 9 голосних
u.pratyahara('hal')                 # → 32 приголосні
u.pratyahara('Sar')                 # → [ś, ṣ, s] — 3 шиплячі

# Тести природних класів
u.is_vowel(0x00)                    # → True
u.is_stop(0x25)                     # → True (k — проривний)
u.is_sibilant(0x29)                 # → True (s — шиплячий)
```

## Ключові рішення

1. **Аліасинг h**: Звук h зустрічається в с̄утрі 5 (позиція 1) та с̄утрі 14 (позиція 1). Обидві позиції мають код 0x09. Входження в с̄утрі 14 записане як `alias_sutras: [14]`.

2. **Нерозв'язані IPA**: Деякі фонеми мають спірні IPA значення. Вони позначені `ipa: "unresolved"` зі списком `ipa_candidates`, без примусового вибору одного значення. Це не помилка — це інформація.

3. **Українські спільні коди**: 13 українських фонем є сегментно-еквівалентними канонічним звукам санскриту та використовують їхні коди. Канонічний запис отримує під-словник `languages.ukrainian` з українською літерою, IPA та типом відношення.

4. **Багатосимвольні літери**: Українська має багатосимвольні літери (дж, дз, ць, дзь, щ тощо). Енкодер використовує жадібний пошук найдовшого збігу (greedy longest-match).

5. **Пратьāхāра замість бітових масок**: Канонічні коди впорядковані за послідовністю с̄утр, а не за фонетичними ознаками. Тому `(code & mask) == constant` не працює на канонічних кодах. Природні класи виражаються через пратьāхāра — панініївський механізм, який є системою природних класів, але не бінарною. Для апаратної реалізації пратьāхāра може бути pre-computed у bitmap: `pratyāhāra → 256-bit bitmap`, тест належності = `bitmap[code]` (один доступ до пам'яті).

6. **Розділення форматів**: UPC-8 — це **формат обміну** (interchange), стабільний і канонічно обґрунтований. Окремо (в майбутньому): **формат виконання** (execution) — впорядкований за ознаками, оптимізований для апаратних тестів `(code & mask) == constant`; **формат зберігання** (storage) — стиснутий, для файлів/передачі.
