# Прототип Bitmask64
*Змістовний переклад README.md*

Розширення ідеї PVC16 до 64-бітних масок, що дозволяє вмістити ширший набір фонем та додаткових морфологічних чи граматичних ознак в одне ціле число. 

Спрямоване на уникнення динамічного виділення пам'яті (allocations) під час базових фонетичних операцій, що узгоджується з нашими вимогами до ABI (швидкість, відсутність збирача сміття).
