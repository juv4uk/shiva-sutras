# Design-level cost of three queries on the 7-bit prototypes (research, hypothesis)

Protocol of SENS #1987: parity before timing, Cachegrind I refs (`--cache-sim=no`), setup and full runs differenced, median of 3.
The tables (`tables.h`) are generated by `gen_tables.py` from the REAL prototypes (`survey_7bit.py`) and from the UPC-14 graph oracle.

Designs: H hand table, D saṅkṣepa7 (derived), V varṇa7 are **geometry** (the answer is read from the bits by a rule);
A akṣara7, T tantu7, L legacy are **ordinals** (the cell is an index; the answer needs a table or an interval).
Queries: `sav` savarṇa(a,b) (1.1.9), `ac`, `jhal` (membership in a pratyāhāra).

```bash
python3 prototype/bench_7bit/run.py --out docs/upc7-design-query-bench-2026-10-01.tsv    # gcc, valgrind
```

## Parity first (answers against the graph, no timing is meaningful without it)

| design | savarṇa mismatches of 1764 ordered pairs | ac of 42 | jhal of 42 |
|---|---|---|---|
| H hand table | 6 | 0 | 0 |
| D saṅkṣepa7 | 4 (= e~ai, o~au: not decided by the sources) | 0 | 0 |
| V varṇa7 | 4 (the same) | 0 | 0 |
| A, T, L (ordinals) | 0 **by construction**: their table is filled from the graph's answer | 0 | 0 |

## I refs per call (GROSS: the call loop and rng are included and are the same for every design; read the differences)

| query | geometry (H, D, V) | ordinals (A, T, L) | difference |
|---|---|---|---|
| savarṇa | 87.7 | 81.0 | ordinal 6.7 cheaper |
| ac | 133.9 | 136.0 | geometry 2.1 cheaper (a class test) vs an interval compare |
| jhal | 132.2 | 132.0 | none (the same mask test in every design) |

Preparation (once): ordinals build the savarṇa row table (42 rows × 8 bytes): about 9,950 I refs more than geometry, which has no table.

## What it says

1. **The query cost does not separate the designs**: the differences are single-digit instructions per query, inside what a compiler's
   scheduling can move. Nothing here is a reason to prefer a family.
2. **What separates them is where the knowledge lives**: geometry reads savarṇa from the bits with a rule (no table) but carries the
   rule's mismatches (4 for D and V = the e~ai / o~au pairs the sources do not decide; 6 for H, adding r~l, a defect of the hand placement);
   ordinals are exact only because a 336-byte table was filled from the graph, i.e. the knowledge is copied, not derived.
3. `ac` is a class test in geometry (3 instructions) and an interval compare in ordinals; `jhal` needs a mask in every design.

## Limits

I refs only; one CPU and compiler (i5-6400, gcc 16.1, `-O2`); three queries, not the whole language; the numbers include the common
loop and rng, so absolute values are not meaningful; no data-cache effects; the sandhi / vowel queries and text encode/decode are not
measured; the geometry rule is the one in `survey_7bit.py` (read from the bits), not a hand-optimised one.
