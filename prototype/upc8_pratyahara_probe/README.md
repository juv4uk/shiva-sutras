# UPC8 → Pratyāhāra Probe

**Статус:** engineering prototype · **Дата:** 2026-08-23
**Автор:** Оксі (Vyasa) · **Дистанції:** ORIENTATIONAL (див. §7)
**Запуск:** `python3 probe.py` (потрібен PyYAML)

## 1. Питання прототипу

Коли українські фонеми закодовані в UPC-8 (ознаковий простір
`prototype/slavic_phonetics/`), то в які пратьяхари Паніні вони
потрапляють? Хто їх найближчий санскритський сусід — і наскільки
далеко?

Це міст між двома шарами екосистеми: канон Шіва-сутр (Layer 1,
immutable) ↔ UPC-8 розширення для словʼянських звуків.

## 2. Метод

1. **Канон.** `ksetra/canon/siva-sutras.yaml` (IMMUTABLE v1.0)
   читається як послідовність `(звук, it-маркер)` у порядку сутрапāṭхи.
2. **Пратьяхари.** Pāṇini 1.1.71: pratyāhāra XY = усі звуки від
   першого входження X до **кінця сутри, чиїм it-маркером є Y**
   (маркер належить останньому звуку сутри — це була помилка v1:
   брався перший звук із маркером, і `ac` втрачав `au`).
3. **Спільний ознаковий простір.** 4 виміри для обох мов:
   - place: 0 labial · 1 dental · 2 postalveolar · 3 palatal ·
     4 velar · 5 glottal · **6 retroflex** (тільки санскрит;
     відсутність у українській — інформація про відстань);
   - manner: 0 stop · 1 affricate · 2 fricative · 3 nasal ·
     4 liquid/semivowel · 5 vowel;
   - voiced: 0/1; soft (palatalized): 0/1.
4. **Метрика.** Зважена манхеттенська відстань:
   `2·|Δplace| + 2·|Δmanner| + 1·|Δvoiced| + 0.5·|Δsoft|`.
   Ваги підібрані так, щоб місце й спосіб домінували над дзвінкістю.
5. **Звіт.** Для кожної зондованої укр фонеми: найближчий
   санскритський звук, дистанція, список пратьяхар, що містять цей
   звук.

## 3. Анкери калібрування (мають триматись завжди)

| Укр | Очікуваний sa | Результат |
|---|---|---|
| п | p | OK |
| б | b | OK |
| т | t | OK |
| н | n | OK |

Якщо хочеться анкер провалився — метрика/ознаки зіпсовані, інтерпре-
тації не підлягає.

## 4. Перший зріз результатів (14 фонем)

- **і, и → ac напряму** (дистанція 0–0.5): голосні української
  проєктуються в ac без посередників.
- **б/п/д/т/ґ/м/н/в → dist 0.0**: точні відповідники існують
  (labial/dental/velar серії збігаються повністю).
- **й → y (0.5)**, **ч → c (0.5)**: палатальність дає половинку.
- **ж → ś (3.0)**: найбільший зазор — ж посталвеолярний дзвінкий,
  найближчий санскритський палатальний глухий фрикатив; ретрофлексна
  ṣ ще далі. Прірва реальна і вона в числах.
- **Ретрофлекси (ṭa-varga, ṣ)** недосяжні для укр фонем — дистанція
  велика за побудовою. Це *інформація*: в UPC8 нема ретрофлексного
  місця, бо його немає в українській.

## 5. Що це означає (обережно)

Попередня підтримка тези власника (21-23.08): **українська фонологія
проєктується на систему Паніни**, причому щільніше, ніж наївно можна
очікувати (8 з 14 фонем з дистансією 0). Але це M0: ознаки
hand-curated, метрика одна, фонем 14 з ~35.

## 7. Обмеження / ORIENTATIONAL

1. Ознакові присвоєння hand-curated M0 — не звірялись з фонологічним
   довідником; потрібен другий свідок (Sarvam / довідник).
2. Одна метрика; не перевірено проти альтернативних ваг.
3. Аспірація (kh/gh/th/dh...) не має окремого виміру — зливається з
   непросиченою парою.
4. Приклади-пари «укр↔са» тут — про **системну близькість фонем**,
   НЕ про етимологію. Етимологія живе в cognates-uk-sa.yaml зі своїми
   статусами confirmed/pending.
5. Дистанції ORIENTATIONAL до звірки ознак незалежним свідком.
