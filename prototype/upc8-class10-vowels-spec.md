# UPC-8 Class 10 — Голосні (Vowels) — Специфікація

## 1. Кодове розташування

```
0x80–0xBF : class 10 (vowels)
[7:6] = CLASS = 10
[5:3] = PLACE (ряд артикуляції, крок 0x08 = 8)
[2]   = bit 0x04 — FREE (резерв для мовних розширень)
[1]   = NASAL (назалізація)
[0]   = LENGTH (довгота / vṛddhi-пара)
```

## 2. Таблиця рядів

| Ряд | Код бази | short | +0x01 long | +0x02 nasal | +0x03 nasal+long |
|-----|----------|-------|-----------|-------------|------------------|
| a   | 0x80 | a   | ā  | aṃ | āṃ |
| i   | 0x88 | i   | ī  | iṃ | īṃ |
| u   | 0x90 | u   | ū  | uṃ | ūṃ |
| ṛ   | 0x98 | ṛ   | ṝ  | ṛṃ| ṝṃ |
| ḷ   | 0xA0 | ḷ   | ḹ  | ḷṃ| ḹṃ |
| e   | 0xA8 | e   | ai | eṃ| aiṃ |
| o   | 0xB0 | o   | au | oṃ| auṃ |
| —   | 0xB8 | reserved row | | | |

7 рядів × 4 комбінації = **28 зайнято**. Вільні коди: 0xB8–0xBF (8) + модифікатори з bit[2]=1 (36) = **44 вільних**.

## 3. Інваріанти

1. **Śiva Sūtra порядок у коді:** для рядів 0–6 послідовність базових кодів зростає згідно з канонічним порядком a < i < u < ṛ < ḷ < e < o. Тому range-предикати pratyāhāra лишаються простими порівняннями.
2. **+0x01 = довгота, +0x02 = назалізація** — ортогональні біти, сума = обидва.
3. **e→ai, o→au** — vṛddhi-пари, закодовані як поверхнева довгота (кодувальна конвенція, НЕ фонологічне твердження; діахронія живе в transform-шарі, Крок C).
4. **bit[2] (0x04) = FREE** — не використовується в Sanskrit-шарі; резерв для мовних розширень (напр. слов'янські ę ą).

## 4. Предикати (співставлення з HTML-експериментом)

| Pratyāhāra | Коди (short, ряди) | Статус |
|------------|--------------------|--------|
| ac  | 0x80, 0x88, 0x90, 0x98, 0xA0, 0xA8, **0xA9(ai), 0xB0, 0xB1(au)** | EXACT — 9 канонічних голосних (7 short + ai, au) |

> Bit-предикат для всіх 14 голосних (short+long, без назалізації):
> `class==10 & nasal==0 & free==0` → 14 кодів (a ā i ī u ū ṛ ṝ ḷ ḹ e ai o au).
| aṇ  | 0x80, 0x88, 0x90, 0x98, 0xA0 | EXACT — 5 (сутри 1–2) |
| ik  | 0x88, 0x90, 0x98, 0xA0 | EXACT — 4 (i,u,ṛ,ḷ) |

Виправляє неузгодженість v2-HTML (`aṇ @ class==10 & code<0x88` виключав i).
