# Прототип Swarm Dashboard (Панель керування Роєм)
*Змістовний переклад README.md*

Ця директорія містить прототип візуальної панелі для моніторингу рою агентів екосистеми (swarm nodes). 

## Функціональність
Відображає поточний стан задач (з `tasks.my`), статус кожної ноди (очікування, робота, помилка) та історію подій, які транслюються через механізм anti-entropy. Панель слугує інструментом для швидкого огляду топології та навантаження в системі, не втручаючись при цьому в сам протокол.
