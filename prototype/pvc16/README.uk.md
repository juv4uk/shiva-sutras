# Прототип PVC16
*Змістовний переклад README.md*

Цей прототип перевіряє можливість кодування фонологічної системи Паніні (Шива-сутри та пратьяхари) за допомогою 16-бітних бітових масок для ефективного зіставлення на рівні машини.

## Основні концепції
- Кожна фонема отримує 16-бітну маску.
- Пратьяхари (класи фонем) компілюються у складені бітові маски.
- Операції перевірки приналежності до класу зводяться до швидких бітових операцій (AND/OR).

Це дослідження є частиною ширшого пошуку механізмів (Rust/Lisp), де Lisp описує фонетичні правила, а механізм накладає бітові маски для швидкого обчислення.
