UPC-8: Фонемна геометрія простору
16×16 = 256 кодів. Сусідство в просторі = фонологічна близькість.
class 00 — Varga
class 01 — Non-varga C
class 10 — Vowels
class 11 — Signs
reserved
Вже існуюча геометрія в class 00
Горизонтальна близькість (в межах ряду): 0x00 к, 0x01 қ, 0x02 ґ, 0x03 ғ, 0x04 ҥ.
Кожен крок +1 = одна фонологічна ознака змінена: придих, дзвінкість, назалізація.

Вертикальна близькість (між рядами): 0x00 к → 0x08 ч → 0x10 ṭ → 0x18 т → 0x20 п.
Кожен крок +8 = зміна місця артикуляції: велярний → палатальний → ретрофлексний → дентальний → губний.

Діагональ: 0x00 к → 0x09 ҷ (K→C + asp). Це вже фонологічна відстань у двовимірному просторі.

Тобто кодова відстань Хеммінга корелює з фонологічною відстаню. Це не випадковість — це архітектура.
Пропозиція для class 01 (non-varga consonants)
Якщо розташувати їх за фонологічною близькістю до varga-рядів:

0x40–0x47 — K-проксимальні: й (palatal approximant ≈ C), х/г (velar fricative), ґ' (ejective?)
0x48–0x4F — C-проксимальні: ш (postalveolar fricative), ж (voiced postalveolar)
0x50–0x57 — Ṭ-проксимальні: ша (retroflex fricative), жа (voiced retroflex)
0x58–0x5F — T-проксимальні: р (trill), л (lateral), с (alveolar fricative), з (voiced alveolar)
0x60–0x67 — P-проксимальні: в (labial approximant), ф (labial fricative)

Тоді 0x40 + 0x08 = 0x48 — перехід від K-проксимальних до C-проксимальних зберігає ту саму логіку місця, що й у varga.
Пропозиція для class 10 (vowels)
Голосні можна структурувати за рядами артикуляції (аналог place у приголосних):

0x80–0x87 — гортанний/нейтральний: а, ā
0x88–0x8F — твердопіднебінний: і, ī, е
0x90–0x97 — м'якопіднебінний: у, ū, о
0x98–0x9F — ретрофлексний: ṛ, ṝ
0xA0–0xA7 — зубний: ḷ, ḹ
0xA8–0xAF — дифтонги: ai, au + резерв

Усередині кожного блоку: короткий, довгий, можливо назалізований. Це дозволяє +1 = довгота, +2 = назалізація.
Мовний профіль як підмножина простору
Санскритський профіль підписується на 0x00–0x27 (varga) + 0x80–0xAF (голосні) + кілька кодів з 0x40–0x67 (й, р, л, в, ś, ṣ, s, h).

Український профіль підписується на іншу підмножину: 0x18–0x1F (T-row), 0x20–0x27 (P-row), 0x58–0x5F (р, л, с, з), 0x88–0x8F (і, е), 0x90–0x97 (у, о), плюс 0x48–0x4F (ш, ж) як окремі фонеми.

Жоден профіль не «володіє» кодом. Код — це точка універсального фонологічного простору, а профіль вирішує, які точки є фонемами, які — алофонами, які — недопустимими.
