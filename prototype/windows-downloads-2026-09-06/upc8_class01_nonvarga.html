Підсумок: class 01 має структуру
Не lookup table — а формула. Кожен код 0x40–0x7F обчислюється як:

code = 0x40 + (place × 8) + (manner × 2) + voice

Геометрія місця збережена: K→C→Ṭ→T→P = +8 кожен крок, точно як у varga (class 00).

Геометрія манери: fricative→approximant→trill→lateral = +2 кожен крок.

Геометрія голосу: voiceless→voiced = +1.

Language profile як підмножина: санскрит використовує 8 точок (ś, ṣ, s, h, й, в, ṛ, р, ḷ, л), українська — інші 8 (х, г, ш, ж, з, с, ф, в). Жодна мова не «володіє» кодом.

Резерв: 64 − 16 = 48 вільних точок для майбутніх мов (арабські фарингальні, африканські кліки, кавказькі ефрикати тощо).
