Приклад: Паніні 6.1.77 «iko yaṇaci» → машина
; Паніні (500 BCE) ; 6.1.77: iko yaṇaci ; «i, u, ṛ, ḷ перед голосним → y, v, r, l» ; Приклад: madhu + a → madhva ; UPC-8 (2026) ; ik = {0x88, 0x90, 0x98, 0xA0} ; i, u, ṛ, ḷ ; yaṇ = {0x4B, 0x63, 0x5D, 0x5F} ; y, v, r, l ; ac = {0x80–0xAF} ; усі голосні ; Умова: X ∈ ik AND Y ∈ ac → X' = map(X, yaṇ) // Verilog для GW5A-25 module iko_yanaci ( input wire [7:0] x, // поточний звук input wire [7:0] y, // наступний звук output reg [7:0] x_out, // результат output reg changed ); // Pratyāhāra predicates — zero LUT wire is_ik = (x == 8'h88) | (x == 8'h90) | (x == 8'h98) | (x == 8'hA0); wire is_ac = (y[7:6] == 2'b10); // class 10 = vowels // Mapping: ik → yaṇ (lookup table, 4 entries) always @(*) begin changed = 1'b0; x_out = x; if (is_ik && is_ac) begin changed = 1'b1; case (x) 8'h88: x_out = 8'h4B; // i → y 8'h90: x_out = 8'h63; // u → v 8'h98: x_out = 8'h5D; // ṛ → r 8'hA0: x_out = 8'h5F; // ḷ → l endcase end end endmodule
Чому це «перший крок до граматики Паніні»
Паніні створив мову для опису мови — метамову. Але його метамова була розрахована на людину. Він міг сказати «перетвори і на я перед голосним» — і граматик розумів, що робити.

UPC-8 робить те саме, але мова стає виконуваною. «Перетвори і на я» — це більше не інструкція для людини. Це:

if (is_ik(x) && is_ac(y)) x_out = map_ik_to_yan(x);

І це виконується за один такт FPGA (~10 нс на GW5A-25).

Наступний крок — не одне правило, а каскад. Як Паніні мав 4000 sūtra, так і машина може мати 4000 правил, організованих у pipeline. Кожне правило — одна стадія. Вхід — морфема. Вихід — згенероване слово.

Це не заміна Паніні. Це механізація Паніні. Його логіка, його структура, його геометрія — але в залізі.
