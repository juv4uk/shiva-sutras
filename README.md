# Дослідження Śiva-sūtras та Епістемічний Пайплайн

Цей репозиторій перетворився з простого «математичного дослідження Śiva-sūtras» на **експериментальну систему моделювання формального знання**, де граматика Паніні є ідеальним тестовим об'єктом.

Ми діємо як **дослідники, а не знавці**. Будь-який негативний результат (спростування гарної гіпотези) є розширенням карти знань. 

## Два проєкти в одному

Фактично, у цьому репозиторії живуть два великі дослідження:

### А. Математична модель Śiva-sūtras
Дослідження комбінаторних та топологічних властивостей системи Паніні (42 класи).
- **Результати**: Доведено, що для заданих 42 множин абсолютний мінімум маркерів ($M_{min}$) дорівнює **14**. Доведено, що канонічна структура є єдиною, що уникає колізії імен.
- Повні результати зібрані у [**RESEARCH_MAP.md**](./RESEARCH_MAP.md).

### Б. Epistemic Pipeline (Сліпа реконструкція)
Щоб уникнути циклічної аргументації (досліджувати модель, маючи наперед задані класи), ми побудували систему, яка повинна вивести ці класи "наосліп" з тексту.
- **Результати**: Система еволюціонувала у строгу модель розпізнавання власного незнання. Вона навчилася розрізняти відтворюваність і автентичність (`Reproducibility ≠ Authenticity`) та жорстко маркувати брак доказів (`UNRESOLVED-BY-EVIDENCE`).
- Деталі у [**RESEARCH_MAP.md**](./RESEARCH_MAP.md).

## Структура репозиторію

Репозиторій моделює не лише предмет, а й сам процес пізнання:

- `ksetra/` — Поле фактів і джерел.
- `hypotheses/` — Те, що ми припускаємо (ранні ідеї заморожено).
- `experiments/` — Те, чим ми атакуємо припущення. Містить підкаталог `historical_archive/` зі старими версіями скриптів, які збережено для історії дослідження.
- `journal/` — Незмінний літопис зміни нашого знання (Immutable Research Journal).
- `tests/` — Машинні інваріанти.
- `docs/` — Методологія та літопис. Містить [Research Index (Індекс Експериментів)](./docs/research-index.md).
- `.agents/rules/` — Правила та обмеження самого дослідника.

👉 **Почніть дослідження з [RESEARCH_MAP.md](./RESEARCH_MAP.md), щоб побачити актуальний статус усіх ключових гіпотез.**
