# Śiva-sūtras · Епістемічне дослідження

Фундаментальне дослідження системи **Śiva-sūtras** (граматика Паніні) і водночас **експериментальна модель формального знання** — як відрізняти доведене від припущеного.

Ми діємо як **дослідники, а не знавці**. Негативний результат (спростування гіпотези) — теж розширення карти знань.

## Два проєкти в одному

### А. Математична модель Śiva-sūtras
Комбінаторика і топологія 42 класів Паніні.
- Глобальний мінімум маркерів **14**
- Канонічна структура — єдина, що уникає колізії імен (у межах моделі)

### Б. Epistemic Pipeline (сліпа реконструкція)
Щоб уникнути циклічної аргументації, пайплайн має виводити класи «наосліп» з тексту і жорстко маркувати брак доказів (`UNRESOLVED-BY-EVIDENCE`).

## Структура

```text

experiments/   — атаки на припущення (+ historical_archive/)
journal/       — незмінний літопис знання
tests/         — машинні інваріанти
docs/          — методологія, claims-export, coordination
```

Правила для агентів: `.agents/rules/` · [AGENTS.md](AGENTS.md)

## Координація

`shiva-sutras` — upstream-епістемічний авторитет: експортує claims (ID, статус, evidence, scope), **не** архітектурні поради downstream (напр. `my-lisp-panini`).  
Контракт: `docs/epistemic-coordination.md` · реєстр: `docs/claims-export.yaml`
