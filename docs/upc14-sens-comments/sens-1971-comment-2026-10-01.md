**Evidence from the UPC-14 lab (juv4uk/shiva-sutras, experimental, not authority).** A comment for #1971 only; no SENS code touched. Different domain (a fixed alphabet of 42 sounds), so this is evidence about the *method*, not about bit widths.

Problem we solved: serialize a sequence of already-bounded identity cells (codes) into text in three scripts whose tokens have variable length (1-3 code points: `k`, `kh`, `ā̃`, `джг`) and decode it back uniquely.
- **Boundary lives outside the identity.** A separator character outside the token alphabet (`·`, U+00B7) is emitted only where plain concatenation would read differently, decided by a local test: `decode(prev_token + token) == (prev, token)`. Devanāgarī needs none (its writing system is already unambiguous).
- **Strict canonical decoder.** `decode_text` accepts only what `encode_text` writes: if a string is accepted, `encode(decode(t)) == t`, so text ↔ sequence is a bijection on accepted strings; other spellings are rejected (or accepted only with an explicit non-strict flag).
- **Falsification we ran (each item of your list that applies):** two different sequences giving the same text (injectivity): 0 collisions in 3×60,000 random pairs; payload read as boundary: none, because the decoder reads the longest token and the separator is not a token; round-trip of every sequence of length 1-2 over 62 symbols in all three scripts exhaustively, random length 4-14 (3×40,000), 100,000 random strings per script for the strict-bijection property: 0 failures. The coordinator reports exhaustive length 1-3 (205,379 triples, 0 failures; not rerun by me).
- **A real counterexample class:** codes *outside* the declared alphabet (pluta, a long vowel that does not exist) were spelled silently as another sound, a fail-open decode; fixed to raise. Lesson for any transport: the encoder must refuse what the decoder cannot read back.
- **Cost reported separately:** on uniform random sequences, code points per sound 1.27 (IAST), 1.63 (Cyrillic), 1.52 (Devanāgarī); separators per sound 0.005, 0.0012, 0.

What does not transfer: a binary stream has no spare symbol outside the payload alphabet (hence your header/escape), and our `·` costs nothing in the semantic alphabet. The reusable part is the local mechanical unique-decodability test + strict canonical decoder + counterexample hunt.
