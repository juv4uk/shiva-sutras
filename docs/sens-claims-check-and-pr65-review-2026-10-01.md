### Підсумок частини 1

Точні числа в усіх таблицях збігаються з файлами. Три місця, де формулювання сильніше за докази:
1. **«B самозавершується під нульовим padding»** (#1980, #1599 16:15): правда для lazy-читача на словах ≤4 біти й ≤3 слів. Пропоную додавати «(lazy reader, ≤4-бітні слова, ≤3 слова; strict reader помиляється в 74%)».
2. **Parity до k=12, ціни до k=16** (#1988): додати «parity перевірено для k≤12».
3. **Порядок «B<D<A<C»** (#1988): це лише для k≥4; для k≤2 A<D.
Дрібниці: «6.5 MB для A» (це різниця з B); «two different» замість «two or more».

Лишається не перевірено: твердження про SENS-код (#1700, lock, admission), незалежні рев'ю #1983-#1985, її harness.

**Недоліки методу (не помилки README, але варто додати до Limits):**
1. `bench7.c` у циклі викликає `strcmp(q, …)` для вибору запиту на **кожен** виклик; тому числа різних запитів (`null` 98, `sav` 87.65, `ac` 133.86, `jhal` 132.22) не можна порівнювати між собою (`sav` дешевший за `null`, бо в нього менше strcmp). Порівняння **між дизайнами** в межах одного запиту коректне, і README саме на ньому будує висновок.
2. Для H, D, V I refs ідентичні до сотих (87.65/133.86/132.22), бо виконується той самий код на тому самому розподілі: це не три вимірювання, а одне.
3. `ac` для геометрії не має інтервалу: `AC_CONTIGUOUS=0` для H, D, V (ac не суцільний у кодах), але ординальні A, T, L мають 1; README про це не згадує, а саме це й пояснює різницю «клас-тест проти інтервалу».
4. `run.py` у docstring радить `--out docs/research/…`, у README `docs/upc7-…`; шляхи розходяться (косметика). `run.py` перезаписує `tables.h` у дереві при кожному запуску (зараз збігається з закомічним).
5. `survey_7bit.py` містить мертвий вираз `… if False else …` в `structural_savarna` (не впливає на результат).

**Висновок щодо #65:** код і числа відтворюються, README загалом чесний. Рекомендую правки: (а) у таблиці parity позначити `jhal` як «за побудовою для всіх дизайнів»; (б) у Limits додати strcmp-диспетчеризацію; Рішення про saṅkṣepa7 у SENS лишається за власником (див. MERGE-SCREEN).
