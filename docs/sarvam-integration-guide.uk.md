# Інструкція з інтеграції Sarvam AI
*Змістовний український відповідник для `sarvam-integration-guide.md`.*

Цей документ описує правила та технічні деталі інтеграції API Sarvam AI в екосистему для обробки лінгвістичних та фонетичних задач, специфічних для індійських мов.

## 1. Мета та обмеження
Sarvam AI використовується як асистент для розпізнавання мовлення (Speech-to-Text), перекладу та фонетичного аналізу. 
**Важливо:** Sarvam AI НЕ є джерелом семантичної правди для правил Аштадх'яї. Семантичний авторитет завжди залишається за WSM/Lisp архітектурою. Всі результати від Sarvam повинні верифікуватися на рівні механізмів екосистеми.

## 2. Ключові ендпоінти
- `speech_to_text`: Перетворення аудіо на текст (індійські мови).
- `translate_text`: Переклад між англійською та підтримуваними локальними мовами.
- `transliterate_text`: Транслітерація (наприклад, з Devanagari у IAST).

## 3. Обробка помилок та Rate Limiting
- Інтеграція повинна коректно обробляти помилки мережі та ліміти запитів (HTTP 429).
- Обов'язкове використання патерну Exponential Backoff для повторних запитів.
- Агенти не повинні переривати виконання базових операцій, якщо Sarvam тимчасово недоступний (має бути резервний fallback або grace degradation).

## 4. Конфіденційність та безпека
- Усі API ключі повинні завантажуватись через MCP (`mcpServers.sarvam-ai.env.SARVAM_API_KEY`) або знаходитись у файлі `private/secrets.md` (який додано до `.gitignore`).
- Заборонено надсилати приватні або конфіденційні дані користувача до Sarvam API без попередньої санітизації.
