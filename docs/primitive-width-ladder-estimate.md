# Оцінка ширини драбини примітивів / Primitive-width ladder estimate

**Статус:** дослідницька оцінка, не специфікація.

Ця нотатка фіксує початкове питання: скільки бітів потрібно на різних
рівнях, якщо рухатися від малих примітивів до правил і граматичних структур.
Фінальна архітектура ще не визначена.

## Початкові числа

- канон Śiva-sūtras: **42 унікальні звуки** у 43 позиціях;
- канонічні лінії: **14**;
- UPC-коди канону з поточними розширеннями: приблизно **80**;
- сутри в поточному реєстрі Aṣṭādhyāyī: **3983**.

## Мінімальна адресація

```text
42 звуки       → ceil(log₂ 42)   = 6 біт
43 позиції     → ceil(log₂ 43)   = 6 біт
14 ліній       → ceil(log₂ 14)   = 4 біти
80 UPC-кодів   → ceil(log₂ 80)   = 7 біт
3983 сутри     → ceil(log₂ 3983) = 12 біт
```

Тому 8 біт придатні для ранніх атомів, але не можуть однозначно адресувати
всю множину сутр. 16 біт — перша зручна ширина для ідентифікатора сутри з
резервом під тип, режим або невеликий контекст:

```text
2¹¹ = 2048  — замало для 3983
2¹² = 4096  — теоретично достатньо
2¹⁶ = 65536 — практичний простір наступного експерименту
```

## Драбина як гіпотеза

```text
8 біт   — примітив, звук, мала операція
16 біт  — правило або складений атом
32 біти — правило з операндами й контекстом
64 біти — робочий атом деривації, маска, provenance
далі    — послідовність або граф атомів
```

Це не означає, що граматика повинна бути одним 64-бітним словом. Треба
розділяти:

```text
ідентифікатор правила ≠ опис правила ≠ стан деривації ≠ повна граматика
```

3983 бітів вистачило б лише для bitmap «це правило присутнє». Це не є
кодуванням змісту граматики. Зміст потребує операцій, операндів, областей
дії, успадкування контексту, конфліктів і історії деривації.

## Межа знання

Точну ширину «всієї граматики» зараз порахувати неможливо: ще не визначено,
що є примітивом, які поля є обов'язковими і чи ділитимуться правила спільними
таблицями. Цей документ фіксує лише нижні інформаційні межі для наступних
малих експериментів.

## English summary

This is an exploratory lower-bound estimate, not a final encoding design.
Eight bits are a starting carrier; twelve bits are the theoretical minimum to
address 3983 registered sūtras; sixteen bits are the first practical rung for
a rule identifier plus small metadata. Full grammar size remains undefined
until the primitive and derivation model are specified.
