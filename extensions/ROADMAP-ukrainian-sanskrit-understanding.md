## 1. Крок 1 — Спорідненості стають даними (Cognates as Data)

Таблицю з валту → `extensions/cognates-uk-sa.yaml`:

```yaml
meta:
  version: "0.1"
  source: "Sanskrit Terms Index (валт), 2026-08-20"
entries:
  - sa: bhrātṛ          # भ्रातृ
    devanagari: भ्रातृ
    uk: брат
    pie: "*bʰréh₂tēr"
    status: confirmed   # ✅ підтверджено
```

~40 записів з індексу. Детерміновано, версійовано, provenance збережено.

**Верифікація:** кожен запис має source; статуси confirmed/pending не змішуються.

## 2. Крок 2 — Матриця kāraka ↔ відмінки

Структурний переклад граматичних ролей як дані + тести:

```text
karta       ≈ називний (хто діє)
karma       ≈ знахідний (на кого спрямовано)
karaṇa      ≈ орудний (чим)
sampradāna  ≈ давальний (кому)
apādāna     ≈ родовий відокремлювальний (від кого)
sambandha   ≈ родовий приналежності / звʼязка
```

Дає машині розуміти *хто кому що зробив* обома мовами.
Небезпека, яку фіксуємо заздалегідь: відповідність приблизна
(укр. називний може бути й karta, й bhāva) → матриця з полями
`confidence` і `exceptions`, не бінарна.

## 3. Крок 3 — Двомовні якорі ембедінгів

Експеримент 2026-08-22 (`experiment_devanagari_anchors.py`)
підтвердив: Деванагарі в якорях підвищує доменну чутливість
(nakṣatra ← Āryabhaṭīya ✓), але гола Деванагарі без контексту
народжує атрактори (v2: anubhāva ×191).

Рішення: **гібридні якорі v3** (Деванагарі + IAST + семантика),
плюс українські описи концептів Онтології → пошук в обидва боки:
українське поняття ↔ санскритський текст.

## 4. Крок 4 — Морфологічний міст через panini_nlp

Розширити рушій правил на українські відмінкові закінчення
(~20 продуктивних патернів проти сотень санскритських):

```lisp
(analyze "братом")  → kāraka = karaṇa, число = однина
```

Порядок: закінчення → основи на приголосний → винятки.
Кожен патерн з тестом-фікстурою.

## 5. Крок 5 — Golden set для чесності

50–100 пар uk↔sa (речення/фрази/терміни) з вердиктами власника.
Метрики: retrieval hit-rate (пошук), role-mapping accuracy (морфологія).
Без golden set ми не можемо чесно сказати «розуміємо на X%».

Правило екосистеми застосовується повністю: embedding similarity =
гіпотеза; переклад/розуміння = evidence лише через golden set.

## 6. Чого НЕ робити (свідомо)

- ❌ Fine-tuning BGE-M3 (мало пар, дорого; retrieval достатній)
- ❌ Повний машинний переклад як ціль (ціль — структурне розуміння)
- ❌ Масове автотегування корпусу українськими концептами без ревʼю
