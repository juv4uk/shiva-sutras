# Двоїна ↔ Dvivacana: дуальне число в українській та санскриті

**Статус:** research compilation · **Дата:** 2026-08-23

uk.wikipedia/Двоїна, learnsanskrit.org, Whitney Sanskrit Grammar,

## 1. Спільне походження

Двоїна успадкована з **ПІЄ прамови** → спільнословʼянська → усі словʼянські мови.
Санскрит зберіг її як **живу категорію** (dvivacana, द्विवचन).
Українська втратила як окрему категорію (XIII–XVI ст.), але залишила
**багатші сліди ніж будь-яка інша східнословʼянська мова**.

> Обидві мови успадкували те саме — але санскрит зберіг усього,
> а українська зберегла сліди, які російська втратила повністю.

## 2. Санскрит: dvivacana живий і продуктивний

### 2.1. Три числа
| Число | Назва | Вживання |
|---|---|---|
| eka-vacana | однина | один предмет |
| **dvi-vacana** | **двоїна** | рівно два предмети |
| bahu-vacana | множина | більше двох |

### 2.2. Форми
Двоїна має лише **3 case-forms** замість 7:
- Nom/Acc/Voc: -au (masc/fem), -ī (neut)
- Instr/Dat/Abl: -bhyām
- Gen/Loc: -yoḥ

Але дієслова мають повний набір dual-закінчень для кожного часу:

```lisp
;; приклад: "двоє ведуть"
nayataḥ    ;; dvivacana 3rd person
```

### 2.3. Вживання
Dual використовується СТРОГО для рівно двох обʼєктів:
```text
dyāvāpṛthivī ubhé stām     ;; «небо і земля — обидва нехай будуть»
açvínāu                     ;; «два Açvins» (без слова «два»!)
```

Whitney: *«The dual is used alone (without dva two) properly when
the duality of the objects indicated is well understood.»*

## 3. Українська: двоїна мертва, але сліди всюди

### 3.1. Історія занепаду
```text
ПІЄ прамова → спільнослов'янська → давньоруська
   ↓                                    ↓
   двоїна ЖИВА              початок занепаду (XIII ст.)
                                        ↓
                            завершення (~XVI ст.)
```

### 3.2. Залишки в сучасній літературній мові

| Категорія | Форма | Приклад |
|---|---|---|
| Орудний мн. | **-има** (замість -ами) | очи́ма, плечи́ма, двери́ма, гроши́ма, уши́ма |
| Наголос з числівниками | два бра́ти, три верби́, чотири відрá | (мн.: бра́ти, се́стри, ру́ки, ве́рби) |
| Числівник | **двісті** (< два ста) | |
| Числівник | **дванадцять** | |

### 3.3. Залишки в діалектах (значно багатші!)

| Говірка | Форма | Приклад |
|---|---|---|
| Пд.-зах. | Наз.в. жін. рід з -і | **дві сестрі**, три вербі, дві руці, чотири відрі |
| Пд.-зах. | Ор.в. мн. -ема/-єма/-ма | братéма, гурубцє́ма, плічéма, двирéма |
| Закарпаття/Гуцульщина | Ор.в. -ома | ножóма, барано́ма, тілома |
| Полісся | Дав.в. -ом/-ем | кіньом, хлóпцьом, гóстьом |

### 3.4. Прислівники від двоїни

**весьма, ревмя, ливмя, летмя, дрожмя, кричмя, торчмя, плашмя, стоймя**

Від двоїни слова *половина*: **полма** («навпіл»).

### 3.5. Дієслова у двоїні (арх.)

```text
въстаста два волъхва        ;; «два волхви встали»
Ивану и Олексию написавшема книгы   ;; «Іван та Олександр написали книгу»
```

## 5. Звʼязок з san-skrít dvivacana

Обидві мови успадкували dual з ПІЄ. Але шляхи різні:

```text
ПІЄ *dwoh₁ (dual)
  ├──→ Sanskrit: dva/dve + dvivacana (LIVE SYSTEM)
  │         verbs have dual endings for every tense/mood/person
  │         strictly used for exactly two
  └──→ Proto-Slavic → Old East Slavic → Ukrainian
            dual existed alongside sg/pl in oldest texts
            began dying XIII c., completed XVI c.
            FOSSILS survive in literary + dialects
```

**Ключова паралель:** обидві мови зберегли сліди — санскрит як живу
категорію, українська як морфологічні викопні. Обидва свідчать про
спільну систему, яка розпалася незалежно в кожній гілці.

## 6. Для uk-sa roadmap

Крок 2 (kāraka матриця) мусить враховувати:
1. Санскритські dual-форми не мають укр еквівалента → переклад через множину
2. Укр -има/-ома форми = сліди двоїни, не активної категорії
3. Діалектні двоїнні форми можуть бути джерелом для відновлення
   якщо колись постане завдання реконструкції повного мосту
